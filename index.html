Tutorial completo para configurar y usar CDraw

Este tutorial reúne los pasos principales para configurar y utilizar CDraw. Lee los apartados en orden la primera vez y vuelve a ellos cuando necesites recordar una función.

1. Crear tu primer dibujo

  1. Entra en Dibujar desde el menú o pulsa Nuevo dibujo en Inicio.
  2. Dibuja con el dedo, un lápiz táctil o el ratón. Mantén el dedo apoyado y arrástralo suavemente.
  3. Usa Color para escoger un color y Grosor para cambiar el tamaño del trazo.
  4. Si te equivocas, pulsa Deshacer. Para recuperar algo deshecho, pulsa Rehacer.
  5. Pulsa Guardar una vez. El dibujo se guardará en la Galería con fondo transparente.

2. Crear una palabra mágica

  1. Primero dibuja en el lienzo. Si ya lo guardaste, puedes volver a cargarlo desde la Galería y editarlo.
  2. Abre Configuración y busca Dibujos mágicos.
  3. Escribe una palabra sencilla, por ejemplo estrella. No es necesario escribir una frase completa.
  4. Pulsa Vincular dibujo actual del lienzo. La palabra aparecerá en la lista.
  5. Para cambiar el dibujo de una palabra, pulsa Editar, modifica el dibujo y vuelve a guardarlo con el botón de actualización.
  6. Para quitar una palabra, pulsa Eliminar. La acción se realiza directamente.
Importante: la palabra se detecta aunque esté dentro de una frase, pero debe pronunciarse completa. Por ejemplo, la palabra mágica estrella funciona en “dibuja una estrella”.

3. Activar y detener la escucha

  1. Ve al lienzo y mantén pulsado el botón Guardar durante dos segundos.
  2. Cuando aparezca el punto rojo y el modo de escucha esté activo, puedes soltar el botón.
  3. El navegador puede preguntar si permites usar el micrófono. Elige Permitir.
  4. Di una frase que contenga una palabra mágica. CDraw cargará automáticamente el dibujo asociado.
  5. Para dejar de escuchar, pulsa discretamente el área de pausa situada en el extremo inferior derecho del lienzo o vuelve a Inicio.

La escucha se activa manteniendo pulsado el botón durante dos segundos. Una pulsación corta del mismo botón guarda el dibujo. La pausa está disponible como un control discreto en el extremo inferior derecho del lienzo.

4. Ver, editar y borrar dibujos

  1. Abre Galería para ver todos los dibujos guardados.
  2. Pulsa una miniatura para abrirla.
  3. Usa Editar para cargarla en el lienzo y modificarla.
  4. Usa Eliminar para borrarla de la Galería.

5. Cambiar colores y apariencia

  • En el menú lateral puedes elegir el color principal de la aplicación.
  • Activa Modo oscuro si prefieres una pantalla oscura.
  • Los dibujos se adaptan automáticamente al modo claro u oscuro. Los trazos transparentes se conservan sin rectángulos de fondo.
  • En Configuración puedes seleccionar el color del fondo del lienzo y el grosor predeterminado.

6. Hacer una copia de seguridad

  1. En Configuración, pulsa Exportar respaldo.
  2. El dispositivo descargará un archivo cuyo nombre empieza por cdraw-respaldo. No lo borres si quieres conservar tus datos.
  3. Guarda ese archivo en un lugar seguro, como tu carpeta de documentos o una nube personal.
  4. Para recuperar los datos, pulsa Importar respaldo y selecciona ese archivo.
Recomendación: exporta un respaldo antes de cambiar de dispositivo, borrar los datos del navegador o desinstalar la aplicación. Los datos se guardan localmente en este dispositivo.

7. Solución de problemas

  • No puedo dibujar: comprueba que estás en Dibujar y toca dentro del lienzo, no sobre la barra inferior. Recarga la página si el problema continúa.
  • No escucha mi voz: usa un navegador compatible, comprueba que el dispositivo tiene micrófono y revisa que el permiso del micrófono esté permitido para esta página.
  • La palabra no activa el dibujo: pronúnciala claramente y revisa que esté escrita en la lista de Dibujos mágicos. CDraw no activa palabras incompletas.
  • No aparece mi dibujo: revisa la Galería. Si cambiaste de dispositivo o borraste los datos del navegador, utiliza Importar respaldo.
  • La aplicación se ve antigua: recarga la página desde Internet. CDraw está configurada para cargar siempre la versión más reciente.

8. Atajos opcionales

En un ordenador puedes usar Ctrl+Z para deshacer, Ctrl+Shift+Z para rehacer y Ctrl+S para guardar. En Mac, utiliza la tecla Command en lugar de Ctrl.
